# Strata

Лёгкий браузер на WPF и Chromium (WebView2), рассчитанный на сотни вкладок. Дизайн взят из папки `Design/`.

## Как работает экономия памяти

Фоновая вкладка проходит несколько стадий:

1. **Скрыта.** Chromium ограничивает рендер и таймеры, а вкладка получает `MemoryUsageTargetLevel = Low`.
2. **Заморожена.** Через 2 минуты (настраивается) вызывается `TrySuspend`. Процесс не тратит CPU, память ужимается.
3. **Спит.** Через 20 минут WebView уничтожается, и вкладка перестаёт занимать память. В дереве остаются заголовок, иконка и позиция прокрутки. Страница загружается заново, когда вкладку открывают.

Есть ещё два предохранителя:

- **Лимит вкладок в памяти.** По умолчанию 12. Сверх лимита засыпают те, что открывали давнее всего.
- **Бюджет памяти.** По умолчанию 4 ГБ на все процессы движка.

Вкладки со звуком или с идущей загрузкой не усыпляются. После запуска сессия восстанавливается со спящими вкладками, поэтому старт мгновенный при любом их числе.

## Импорт из других браузеров

Настройки → «Импорт из браузеров». Автоматически находит Chrome, Edge, Yandex, Brave, Opera, Vivaldi и Firefox и переносит:

- **Закладки** — Chromium читаются из файла `Bookmarks`, Firefox — из `places.sqlite`.
- **Cookie** (сохраняют вход на сайты) — расшифровываются (Chromium: DPAPI + AES-256-GCM) и добавляются в движок. Нужен запущенный движок — откройте любой сайт перед импортом.
- **История** — до 3000 последних записей с исходными датами.
- **Пароли** — только Chromium и только старый формат шифрования. Пароли, зашифрованные app-bound (Chrome 127+, формат v20), и пароли Firefox (NSS) не переносятся — вместо этого импорт cookie сохраняет активные входы. Импортированные пароли лежат в зашифрованном DPAPI хранилище Strata и подставляются автозаполнением.

## Возможности

- **Перевод**: перевод всей страницы (кнопка-глобус или Ctrl Alt T) и быстрый перевод выделенного текста во всплывающем пузырьке. Запросы идут через Google из процесса браузера, поэтому CSP сайтов не мешает.
- **Картинка в картинке**: вынос видео в отдельное плавающее окно (Ctrl Alt P).
- **Поиск Google** с AI-ответами по умолчанию и живыми подсказками в адресной строке и палитре.
- **Жидкое стекло**: системный материал Acrylic под окном; матовые панели и прозрачная стартовая страница поверх размытых обоев (переключается в «Внешний вид»).
- **Закладки**: панель под адресной строкой, сетка на стартовой странице, звезда в адресной строке (Ctrl D).
- **Всплывающие окна**: `window.open` с размерами (вход Google, OAuth, «Поделиться») открывается настоящим окном, а не вкладкой — работают `window.opener`, `window.close()` и обмен `postMessage`; ссылки `target=_blank` по-прежнему становятся вкладками. Всплывающее окно делит профиль с основным, поэтому вход в аккаунт общий, и его можно развернуть в обычную вкладку одной кнопкой.
- **Вход в Google** отображается штатно: движок — настоящий Chromium (Edge WebView2), поэтому Google не показывает «этот браузер небезопасен».
- **Один экземпляр**: повторный запуск (в т. ч. открытие ссылки из другого приложения) выводит уже открытое окно вперёд и добавляет вкладку, а не запускает вторую копию.

- Вертикальное дерево вкладок: ссылки, открытые со страницы, становятся её дочерними вкладками. Ветки можно сворачивать, вкладки — перетаскивать.
- Пространства (Работа, Исследование, Личное…) и закреплённые вкладки, которые видны во всех пространствах.
- Командная палитра `Ctrl K` ищет по вкладкам, истории и командам. Префиксы: `#` вкладки, `@` история, `>` команды.
- Адресная строка с подсказками, разделение экрана `Ctrl \`, режим чтения, заметки к страницам.
- Щит: блокировка трекеров на уровне сети и встроенная защита Chromium от отслеживания.
- История, восстановимые сессии, собственный менеджер загрузок, распакованные расширения Chromium.
- Тёмная, светлая и системная темы, четыре акцентных цвета, три плотности списка. Snap Layouts в Windows 11.

## Сборка

Нужны .NET 8 SDK (или новее) и Microsoft Edge WebView2 Runtime (в Windows 11 он уже установлен).

```bash
dotnet build Browser/Browser.csproj -c Release
```

Публикация с ReadyToRun для быстрого старта:

```bash
dotnet publish Browser/Browser.csproj -c Release -r win-x64 --self-contained false
```

Данные профиля хранятся в `%LOCALAPPDATA%\Strata`.

Шрифты дизайна — Space Grotesk и IBM Plex Mono. Если их нет в системе, используются Segoe UI Variable и Cascadia Mono.
